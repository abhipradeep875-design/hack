Server Secrets & Environment Configuration

Create a local .env from .env.example (or configure the equivalent server-side secrets), then run python server.py from the project folder. Do not open this page directly as a file; the backend serves the page and its translation and transcription APIs.

GEMINI_API_KEY=your_gemini_api_key
GEMINI_MODEL=gemini-2.5-flash
SUPABASE_URL=https://your-project-ref.supabase.co
SUPABASE_PUBLISHABLE_KEY=your_supabase_anon_key
DEEPGRAM_API_KEY=your_deepgram_api_key
DEEPGRAM_TTS_MODEL=aura-asteria-en

Security rule: Keep GEMINI_API_KEY and DEEPGRAM_API_KEY on the server; never expose them in browser code or prefix them with VITE_. The Python backend handles /api/translate and /api/transcribe.
